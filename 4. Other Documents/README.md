# Documentation

Contains technical documentation which outline processes and protocols used during the ETL process and
harmonisation decisions.

Documents will also include common issues, solutions and work arounds.

- 1.challenges_and_solution.docx -> Details specific issues that we had during ETL for MIREDA and any solutions that we used to resolve them.
- 2.ethnicities_omop.xlsx        -> documents the differences between NHS Data dictionary ethnicities, the OMOP race concepts we have mapped to and the codes used for different specificities within the OMOP tables to align our cohorts.
- 3.mat-preg-baby-linkage.svg    -> Diagram illustrating the method used to link mother, pregnancy and baby in MIREDA.
