## 2. OMOP Mappings

This section contains the associated mapping rules as JSON and CSV files for each cohort. All cohorts have included additional content beyond the MIREDA core data but, where possible, all clinical data has been mapped to valid and standard OMOP concepts for SNOMED CT while prescription/medication data is mapped to OMOP valid codes for RxNorm (ingredient-only products) and RxNorm Extension for all others.
Outside of these codes, all efforts were made to use only valid and, ideally, standard coding within OMOP CDM.
